# deribit-client

Сервис периодического сбора index-цен `btc_usd` и `eth_usd` с биржи Deribit
и предоставления их через REST API.

## Стек

- Python 3.12
- FastAPI
- SQLAlchemy 2.0 (async) + asyncpg
- PostgreSQL + Alembic
- Celery + Redis
- aiohttp
